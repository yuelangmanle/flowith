安装指南

几步即可开始使用 Flowith

🍎

macOS 安装

Apple Silicon (M1/M2/M3/M4) 或 Intel Mac

▼
1

下载 DMG 文件

根据你的 Mac 芯片选择对应版本：Apple Silicon 选 aarch64，Intel 选 x64

2

打开 DMG 并拖入应用程序

双击 .dmg 文件，将 Flowith 图标拖到"应用程序"文件夹

3

解除安全限制

打开终端，执行以下命令后即可正常启动：

xattr -cr /Applications/Flowith.app
4

启动 Flowith

双击启动即可。如仍提示"无法验证开发者"，右键点击应用选择"打开"

⚠️ macOS 安全提示：Flowith 是开源应用，未购买 Apple 开发者证书签名。首次安装需执行 xattr -cr 命令移除系统隔离标记，之后可正常启动。
💻

Windows 安装

Windows 10 及以上版本

▼
1

下载安装包

推荐下载 EXE 安装包，也可选择 MSI 格式

2

运行安装向导

双击安装包，按提示完成安装。如出现 SmartScreen 警告，点击"更多信息" → "仍要运行"

3

启动 Flowith

从桌面快捷方式或开始菜单启动，首次使用会进入引导向导配置 AI 模型

📦

从源码运行

适合开发者或需要最新功能的用户

▼
1

克隆仓库

git clone https://github.com/yuelangmanle/flowith.git

2

安装依赖

cd flowith && npm install

3

启动开发服务器

npm run dev，浏览器访问 http://localhost:5173

💡 需要 Node.js 20+。如需桌面应用，运行 npm run tauri:dev 启动 Tauri 桌面版本。
📱

Android 安装

Android 8.0+ 设备

▼
1

下载 APK

从下载区域下载 APK 文件，支持 Android 8.0+

2

安装并启动

下载后点击安装，如提示"未知来源"请在设置中允许。首次使用会进入引导向导配置 AI 模型

📬 移动端支持对话、圆桌讨论、记忆管理、Skills 等全部核心功能。

系统要求

运行 Flowith 的最低配置

🍎 macOS

  • macOS 12 (Monterey) 或更高
  • Apple Silicon 或 Intel 处理器
  • 4 GB 内存
  • 50 MB 可用磁盘空间
  • 网络连接（调用 AI API）

💻 Windows

  • Windows 10 (1903) 或更高
  • x64 处理器
  • 4 GB 内存
  • 50 MB 可用磁盘空间
  • 网络连接（调用 AI API）

📱 Android

  • Android 8.0 (API 26) 或更高
  • ARM64 处理器
  • 3 GB 内存
  • 30 MB 可用存储空间
  • 网络连接（调用 AI API）
