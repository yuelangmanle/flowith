安装和管理 AI 技能插件，Agent 自动学习运用。支持 GitHub 搜索安装、联网搜索、本地文件导入。

代码生成

从想法到可运行代码的 AI 驱动全流程。支持工作空间隔离、多轮修复、代码预览和一键导出。
