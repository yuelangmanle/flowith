# TencentDB-Agent-Memory 调研

> 项目地址：github.com/Tencent/TencentDB-Agent-Memory

## 项目定位

腾讯开源的 Agent 记忆管理系统，专注于解决 AI Agent 的长期记忆问题。

## 核心设计

### 分层记忆架构

```
短期记忆（Short-term Memory）
├── 当前对话上下文
├── 工作记忆（当前任务状态）
└── 自动过期清理

长期记忆（Long-term Memory）
├── 事实记忆（Facts）：用户偏好、历史决策
├── 情景记忆（Episodes）：完整对话场景
├── 语义记忆（Semantics）：知识和概念
└── 程序记忆（Procedures）：技能和操作步骤

外部知识（External Knowledge）
├── 文档知识库
├── API 文档
└── 代码库索引
```

### 关键特性

1. **记忆压缩**：长对话自动压缩为摘要，保留关键信息
2. **记忆检索**：基于向量相似度 + 时间衰减 + 重要性权重
3. **记忆更新**：新信息可以覆盖旧记忆，保持一致性
4. **记忆遗忘**：不重要的记忆随时间衰减
5. **来源追溯**：每条记忆都有来源引用（哪次对话、哪个工具调用）
6. **冲突检测**：检测新旧记忆的矛盾并提示用户确认

### 技术实现

- 向量存储：用于语义检索
- 图存储：用于关系推理
- 时序存储：用于时间线查询
- 混合检索：向量 + 关键词 + 时间 + 重要性

## 对我们的参考价值

我们的 memoryKnowledge.ts 是最基础的实现：
- 只有关键词匹配，没有向量检索
- 没有记忆压缩
- 没有记忆遗忘机制
- 没有冲突检测
- 没有图结构存储

腾讯的方案是生产级的，我们可以分阶段借鉴。
